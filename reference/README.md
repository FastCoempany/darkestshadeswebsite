## technical-drawings/
`drawing-NN.pdf`: the eight 2D technical drawings (A3, 1:1 scale, mm), one per frame, dated Aug 1 2024. The drawing numbers differ from the frame IDs for two pairs: drawing 02 is F03, 03 is F02, 04 is F05, 05 is F04 (`docs/brief/00-decisions.md` O9). Drawing 07 (the dropped frame) is not included. `tools/drawings.py` turns them into vector line art in `content/products/drawings/`.
