## Workspace setup (cloud)

1. **Network access.** Hugging Face, Figma asset downloads and Adobe Fonts are blocked today; PyPI, npm and GitHub work. Where to open it depends on where the session runs:
   - **Claude app workspace** (where this plan was made): on claude.ai in a web browser, **Settings → Capabilities**, under code execution keep **Allow network egress** on and set the allowed domains to **All domains**, or add `huggingface.co`, `*.huggingface.co`, `*.hf.co`, `www.figma.com`, `use.typekit.net`, `p.typekit.net`.
   - **Claude Code on the web** (where Fable builds): open the session, select the caret after the session title, choose **Edit cloud environment**, set **Network access** to **Full** (or **Custom** with the domains above plus the default list). Running sessions pick it up within about a minute.
2. **Setup script** (Claude Code on the web, same dialog), so every session starts ready:
   ```bash
   pip install --break-system-packages -q bpy==5.2.2 pymupdf opencv-contrib-python-headless "rembg[cpu]" pymatting cairosvg pillow numpy scipy scikit-image insightface onnxruntime jsonschema
   ```
   `bpy` is Blender as a Python module (about 350 MB); with the environment cache it installs once.
3. **Fonts**: put the licensed or trial font files in `brand/fonts/private/` (git-ignored), or set `PUBLIC_ADOBE_FONTS_KIT` to an Adobe Fonts web project ID. `brand/fonts/README.md` has both routes.
4. This workspace measured 2 vCPUs and 7 GB RAM: fine for the Python tools and Cycles renders at product sizes; too small to run image-generation models locally (generation stays in Figma).

## Phases and done criteria

**Phase 0: Foundation**
- Scaffold Hydrogen (TypeScript, Tailwind v4) in `app/`. Wire the token CSS, the fonts loader (`brand/fonts/README.md`), `<Logo/>`, `<BrandMark/>`, `<Seal/>`, the mock adapter, Storybook, Playwright, axe, Vitest.
- `tools/flashcheck.py`: renders the entry sequence at 1024×768 and 390×844 and fails on more than three general flashes in any second in any 341×256 window (`03-references.md`).
- CI checks that fail on: hex colors in `app/`; the strings `lorem`, `ipsum`, `% off`, `discount`, `#DarkestShade` (without the s), `Zara in in`, `Model 07`, `Raf`, `Simons`, `Prada` in `app/` or `content/copy/`; product JSON that doesn't match `product.schema.json`; a `draft` or `placeholder` copy string reaching a production build.
- Done when `npm run dev` shows a token test page with both fonts loaded, Storybook runs, and one screenshot test passes at both sizes.

**Phase 1: Wireframes** (wire mode)
- Every template in `04-ia-and-pages.md` at 390 and 1440, every image a labelled `ShotSlot` (`F01-A2 · 4:5`).
- Deliverable: `docs/wireframes/{page}-{390|1440}.png` and a Storybook "Pages" section. **Founder review.**

**Phase 2: Base components**
- Everything in the base table of `05-components.md`, every state, both sizes, axe passing.

**Phase 3: House layer**
- Everything in the house table: entry (with the notice and flash check), bursts, cards, manifesto, detail hold, scale cut, stage cards, drop status with real-data-only countdown and pairs left (unit tests for every missing-data case), spec sheet, line drawings, seal, list form and offer, film grain, header, menu, footer.

**Phase 4: UI pages** (UI mode)
- Pages composed from phases 2–3 with real copy and mock data. Product images from the cleaned set as they land; `ShotSlot` placeholders otherwise.
- Deliverable: `docs/ui/{page}-{390|1440}.png`. **Founder review.**

**Phase 5: Photography**
- Track 1: all eight frames through the lightbox pipeline (`07-photography.md`), A1–A6 plus heroes.
- Track 2: after the casting pick, model bibles, prompt pack, scenes, composites, grade, QC.
- Drop finals into their slots by shot code; `MANIFEST.csv` complete.

**Phase 6: QA and hand-off**
- axe: no serious or critical issues. Keyboard pass on the entry, menu, bag, gallery, pop-up, sign-up.
- Lighthouse mobile ≥ 90 performance on Home, Frames and a frame page with real images; entry assets under 1.5 MB.
- Copy audit against `08-copy.md`; honesty tests green; visual baselines committed.

## Working rules
- Branch per phase, PR into `main`, screenshots on every PR that changes UI.
- Token changes go through `tools/palette.py` (color) and `design/tokens/tokens.base.json` (everything else), then `python3 tools/build_tokens.py`. Never hand-edit generated files.
- Product facts change in `content/products/*.json` only, and only from a source (drawing, factory, founder).
- When `00-decisions.md` doesn't answer a question about brand, product facts, money or legal copy, ask the founder. Otherwise decide and note it in the PR.
